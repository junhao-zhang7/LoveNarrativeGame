# 第三至第五幕互动修订

2026-11-02。依据作者第三幕互动设计和MS-04/MS-05截图要求实现，保留连续播放、章节解锁和本机续读。原有章节资源只在完全匹配上一版时升级，GUID不变；新对白属于为本轮表达选择/合作动作补写，不改变两人互助、归还纸卡和后续约饭的事件结果。

## 第三幕：对视与擦水

“两人同时弯腰”之后增加脸红对视特写，再回到杯盖和拖把对白。特写为内置image_gen参考原场景与角色设定制作的新静态画面，以现有淡入切换，不是逐层脸红动画。原第三幕五图保持。

“我去拿拖把”之后出现地面擦水小游戏：按住鼠标拖动拖把，经过的水渍消失；也可点击“擦下一片”作为替代操作。没有倒计时、失败惩罚或好感扣分。大部分水擦完后显示李晚云“这边还有一点”，点击凌赫“看到了”再补擦椅脚旁的最后水渍；全部清理后才可“放好拖把，回到座位”。随后接“你袖子也湿了”和卷袖口，避免已经回座位却还在拖地的时间倒置。

地板、水渍与拖把是原生UI绘制的互动近景，采用扫过路径的碰撞覆盖，不是流体模拟。快速拖动通过两次位置之间的线段检测，避免跳过中间水渍。两句补擦对白从正文移入小游戏反馈，第三幕正文由18段变16段。

## 第四幕：归还结果相同，表达由玩家选择

李晚云找不到纸卡时，提供“叫她一声，直接递过去”和“夹起纸卡，故作从容”。两者均正常归还，不设正确/错误选择或关系分数，不影响后续解锁。

直接递卡使用新自然递卡图和朴素对白“你的核酸码。我帮你带过来了。”“谢谢，还好你带来了。”；老师提醒其准备好自己的码，凌赫正常跟队。装酷沿用原图、“小姐，你的核酸码”、她害羞与老师“别光顾着耍宝”的反馈。两条均收束到离开时的回头和微笑。取消选择前固定“等会儿再给”的心声，避免玩家已选择自然归还却被强制故意拖延。

表达方式保存到本故事的本机存档，归还后退出重进仍显示对应图和对白；重看可重新选择。原始ScriptableObject数据不被运行时改写，直接递卡通过表现副本替换相关对白和图片。第四幕正文仍20段。

## 第五幕：合作默认可完成，自主解题可选

原强制520输入节点改为合作面板：一起看区间两端 → 记录M=26 → 运用(m+n)²-2mn得到494 → 把本子转给晚云，由她写最后一步。玩家不用输入任何数字也能完成，之后接回原写答、谢谢与约饭。

“我想自己算”可打开输入框，沿用完整题目、520校验和错误提醒；输入前后都能点“先不填了，一起推导”返回当前合作步骤，不清档、不扣分、不阻止剧情。答对自主解题会接原完整讲解；合作路线直接接晚云的最后求和，避免重复整段已经演过的推导。已完成合作可解锁后续，与数学能力无关。第五幕仍29个配置正文节点，合作流程会跳过已经共同演过的讲解节点。

作者检查：
