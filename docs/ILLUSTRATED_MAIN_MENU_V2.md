# 主界面第二版 · 融入教室的菜单

2026-10-31。作者要求按钮融进完整画面、移除字号选项、设置结构参考所附 LoveChoice 截图，语言限定为简体中文 / 繁体中文 / 英语 / 日语。该指示授权本轮修改菜单与设置，不改故事、角色和已确认的座位关系。

## 视觉与功能

- 保留已有暖色手绘教室，去掉左侧独立纸色面板和大按钮底板。标题、菜单直接落在墙面留白上；悬停 / 键盘焦点用短铅笔划线与墨色变化反馈，菜单轻微淡入。
- 设置采用独立的浅色纸张、蓝灰铅笔线条、圆形滑杆与手写勾。参考图仅用于信息结构与手绘气质，未复制其像素、纸张素材或具体装饰；没有导入第三方游戏美术。
- 音乐 / 音效分别设置和保存。新增 MenuAudioChannel，供后续音乐与音效的 AudioSource 分别绑定；目前仍没有正式音频，不能把滑杆数值验证当作听感测试。
- 分辨率菜单列出本机屏幕范围内的常用尺寸并补充原生尺寸。全屏使用 Windows 全屏窗口，窗口模式使用选择的尺寸。不同屏幕上可能由 Unity 选取最接近的尺寸。
- 字号选项及其对互动小样的影响均已移除。恢复默认返回 80% / 80%、1280×720 窗口；保留当前语言，避免玩家重置后看不懂设置页。
- 四种语言真正切换本次主界面、设置和退出框，选项互斥并本机保存。剧情小样仍是作者的简体中文文本，界面有说明；四语正式剧情和母语润色尚未完成。

游戏名称依然是“未定名”占位。开始游戏仍进入数学讲题 / 英语互助灰盒，不宣称主线已制作完。

## 关键实现

MainMenuScreen 负责布局、设置操作和场景入口；MenuPreferences 负责偏好值与显示应用；MenuCopy 集中四语菜单文案；MenuInkGraphic 在 UGUI 中绘制纸边、笔划、勾选框与圆点；MenuHoverInk 处理指针 / 焦点反馈。字体从工程已有 Noto CJK 字体创建运行时 TMP 实例，防止切换语言时把动态字形写回共享资源，退出菜单时释放。

分辨率实现按 [Unity 6000.6 Screen.SetResolution](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/screen/setresolution) 与 [Screen.resolutions](https://docs.unity.com/en-us/engine/6000.6/script-reference/unityengine/screen/resolutions) 核对。手绘控件与 TMP API 同时检查本工程 UGUI 2.6.0 对应 PackageCache 源码；无新增付费依赖或包。
