## 2. 操作语言：给对方留出位置，把手头的事留下来

核心动作限定为摆放、交接、暂存三类。玩家的注意力放在人与物之间，不反复学习新小游戏。普通生活操作约 15–40 秒，核心互动约 45–90 秒为初始目标，答题不设限；这些是待测试节奏，不是已计时数据。

- **摆放**：决定自己桌面怎样腾出可共同使用的区域。不是把物品拼进唯一正确轮廓。
- **交接**：玩家发起一个动作，角色看见并接续它；对方不是只在完成后播放感谢台词的奖品。
- **暂存**：把尚未完成的事标记到可继续的位置，真正腾出时间去见另一个人。中断工作不等于销毁工作。

数学输入仍然保留，是作者指定的校园参与方式；它不独自承担创新卖点。收杯、取核酸码、接书属于短演出互动，不夸大为核心玩法。争执和最终决定可以留给表演，不要求每句话都套一个操作。

## 3. 核心机制 C01：一起完成的动作

### 目的与情感

用于 MS-05、06、16、20、25、26。让亲近表现为“我的动作有人接着做”，而非爱心数值上涨。高潮不依赖操作难度逐步增加，而依赖玩家已经记住对方怎样参与。

### 玩家看见什么

俯视的直角双桌近景，自己的本子、笔和书堆完整可见；李晚云的手与本子边缘在右侧。第一次数学解答完成后，她看向草稿。提示只出现一次：“挪开东西，把这一步给她看。”提供“点击物品，再点位置”的替代方式。

### 具体操作与完成条件

1. 玩家把自己桌上的笔盒或一本书挪入任意可用区，留出一块宽空间。允许上、下两种布局，不规定某个具有道德意义的位置。
2. 玩家把写好的解题页推入共同区域。进入宽目标区后出现对方准备伸手的姿态；松手或点击交接即确认，不要求卡住一帧。
3. 李晚云接住纸边，将纸转到自己能读的方向，在已讨论的步骤旁补写一小行。玩家不是同时控制她的手；这段响应属于她的主动行为。
4. 她将纸推回到玩家实际留出的空位，避开笔盒。玩家接回，看到新增笔迹。交接结束才提交节点，剧情继续。

玩家可以改变物件布局和先移哪件物品。NPC 的交接目标依据布局变化，反馈确实不同，但两种布局都不加减关系分。不要用精确距离、完美对齐或速度评分诱导“最体贴的答案”。

### 同一机制的不同意义

| 场景 | 玩家动作 | 对方如何参与 | 情绪目标 |
| --- | --- | --- | --- |
| MS-05 数学 | 腾出共同区域，递出已完成的步骤 | 她接住、补写自己理解的最后一步、推回 | 第一次一起完成一件小事 |
| MS-06 英语 | 把自己的练习册递过去 | 她翻到前文并留下圈记，玩家按她提示接着看 | 她也有擅长的事，互助有来有回 |
| MS-16 / 20 | 接过她批过的页，放到习惯的位置 | 她的递出更自然，不再停顿等确认 | 熟悉减少了不必要的解释 |
| MS-25 | 接回练习册 | 她交还后收手；没有新批注或共同解题 | 同一交接方式，目的变为归还 |
| MS-26 | 展开自己的练习册，自己翻页并写下答案 | 对方不在当前场景；旧笔迹仍可读 | 玩家继续做完自己的动作，过去没有被删除 |

结尾**不放空的“递给她”热点骗玩家点击，不让手悬空数秒，不阻止玩家自己翻页**。她不在是画面已经告诉玩家的事实；情绪来自主动继续，而非系统拒绝操作。

### 多感官反馈

纸面有轻微压弯的预绘帧，交接时笔声短停，收回时能看到不同方向的字迹。声音随对象位置略有左右差别，重要信息同时视觉显示，不依赖立体声耳机。前期只在交流稳定后进入少量音乐；结尾可以保留同一纸声，不必叠悲伤字幕。

### 状态、异常和退出

只保存 `pageLayoutId`、`sharedPageStage`、已出现的圈记标记；不得把布局解释为性格或感情值。完整交接后保存；退出半途回到当前交接开始，不出现重复笔迹。无效放置缓慢回原位，显示可用区域；不能堵住角色手部导致软锁。自动辅助完成与手动完成具有相同故事结果。

### Unity 与成本

UGUI 纸页、物品图、手部层，宽区域命中与吸附；状态流为“整理—可交接—对方接续—返回—完成”。手的目标取自有限的两套布局，不用物理抓取或实时骨骼求解。内容是定长小步骤，不需要通用叙事编辑器。

新增资产：桌面构图 1，纸 / 书 / 笔盒 3–5 张，双方手势合计 6–8 帧，圈记与字迹图层，纸笔音效 3 类。灰盒中等，约 12–20 小时；正式手部动画和插画另估。低成本版只保留两种摆放结果、每人两帧手部，核心仍是对方接续动作。

**风险与淘汰条件**：如果玩家只说“把纸拖到框里”，不能描述对方怎样接住并参与，机制尚未达标。先改善响应与减少步骤，不能靠添加更多整理杂物冒充深度。

## 4. 核心机制 C02：把未完成留到下次

### 目的与情感

主要用于 MS-16、19、20、22、26。让守约不仅是选“去见她”，而是亲手处理仍在进行的事情。玩家体验自己如何给关系留出时间，又不必把正常学习看成爱情敌人。

### 可见信息与操作

画面左边是正在讲到的习题页，纸上可见最后完成的一行；右边是开着的教室门与约定提示。铃响之前，当前动作会先完成，剧情给出“我先出去一下，晚自习前再讲”。此时才交给玩家操作，没有真实倒计时。

1. 将笔停到当前已完成的步骤，而不是把整题强行讲完。
2. 把可反复使用的窄纸签夹在这一行。任意覆盖该步骤的宽区域都有效；也可直接点击“标在这里”。
3. 合上笔盖，起身走向门口；纸签留在书边。周星落会接受延期，收回自己的本子，不播放失望惩罚。
4. 晚自习前的短回声中打开同一页，纸签带玩家回到那一行；点击继续后完成收束。这是演出补充，不增加新关系情节。

先放纸签还是先盖笔均可；如果没标记就尝试合本，可选择继续收起或补标记。前者稍后先出现“找到刚才那一行”的短定位动作，后者直接回到步骤；两种都完成见面和讲题，没有效率积分。这是玩家行为确实留下的小差异，不扩展人生分支。

### 约定如何落地

MS-19 的约定显示在一张简短课间记事页上，不是满屏排课表。确认“下午第二节下课”和“临时有事先说”后，相关场景自然出现门口方向的提示。MS-20 一次实际出门，一次先去告知；玩家都必须得到可见履约反馈。

MS-22 改为周三午餐后，页面上移除旧的课间安排，保留两人确实商量后的新安排。旧约定可以回看，不能被回忆改写成从未尝试。

### 固定失约的处理

MS-18 中两次失约是剧情演出，**不把本机制做成“明明能标记离开，却按钮失灵”的必输关卡**。该段给出已知约定、完整的讲题片段和铃声过渡，让玩家知道凌赫忘了；可在事后收拾纸页，但不能暗示是玩家算题太慢害她等。

如果未来决定让玩家自由避免这两次失约，就必须同步改剧情；本版不偷改已通过的主线。

### 反馈、状态与退出

盖笔后笔声停止，出门脚步开始；门口她抬头，完成真实见面。纸签再次露出的位置与先前一致。保存 `bookmarkPlaced`、有限 `resumeStepId`、约定与告知事实；不存“是否足够重视她”。读字、菜单、提示均暂停叙事推进。中途退出恢复该步骤，已经告知不会重复说成没告知。

### Unity 与成本

复用 C01 页层，新增纸签与门口提示；当前步骤、暂存状态与场景跳转分开。自动辅助只替代操作，不能删掉告知或履约剧情。资源为纸签 1、笔盖动作 2 帧、门口角色 2 姿态、脚步 / 铃声。中等约 8–14 小时，复用 C01 后估算；正式演出另计。

**风险**：不能变成任务清单。“还有三件事才允许谈恋爱”的设计会破坏自然感；一次只保留标记、收笔、起身中的两到三个动作，完成即获得人的回应。

## 5. 核心机制 C03：两张表，三次方向

### 目的与情感

用于 MS-09、12—15。让迁就的痕迹可见：最初两个人一起想学理，后来凌赫把自己的打算靠向她，最后又回到理科，而“一起在同一个班”的期待不再重合。

### 画面与操作步骤

1. MS-09 聊天后出现凌赫自己的学习记事页。玩家将“理科”意向便签放到自己的页上；旁边显示已收到的“我们说好了”消息。**这是私人意向，不是已提交的正式表。**
2. MS-12 桌面出现两张初选表。李晚云先在自己的表上写史政地。凌赫说完自己也喜欢历史后，玩家把自己的表挪到她旁边，按既定组合填写。位置越过桌面拼接处时，他的笔迹方向与她的不同，保留两个独立的人，而非把名字融合成爱心。
3. MS-13 老师拿出的是已经交过的初选表；玩家可以翻看自己原意向的回忆小页，但不能在办公室直接提交改科。问清并离开。
4. MS-14 商量后，MS-15 才出现变更确认。玩家将原史政地表保留在旁，填写理科变更项并提交。画面结束在两张表都看得见的构图；对话确认“不同班也还在一个学校”。

不把李晚云的表自动推远来象征不爱，也不出现“爱情 / 前途”权重条。两张纸产生的空间变化表达的是实际安排，不能替代人物的商量。

### 玩家自由与后果

可以先看成绩 / 兴趣记录或先看旧约定，得到对应的已知回忆片段；它们不构成解锁条件。学科方向按主线已定，操作负责经历与确认，不摆虚假的任选学科。一次确认提交不可被多次点击重复执行；若在确认前退出，保持未提交。

### 音画、状态、成本

书写声、翻纸声、短停笔；理科和文科用同样的可读配色，不借颜色判优劣。保存 `initialIntent`、`submittedTrack`、`decisionDiscussed`、`changedTrack` 四个事实，严格区分意向与正式提交。

Unity 使用纸页与透明覆盖层、预设文字显现、固定状态节点；无需画笔识别。资源为两种表、一张便签、笔手 2–3 帧。中等约 6–12 小时，复用 C01 后；风险是退化成确认弹窗，因此只在三次方向变化处用，不把每场聊天做成表格操作。

## 6. 辅助机制 S01：没有发出去的部分

用于 MS-07、10、24。承载试探、克制与道歉，但不作为唯一主卖点。

玩家知道哪些是已经给出的消息、哪些仍在自己手里。MS-07 折纸后递出，立刻失去查看宿舍回应的控制；宿舍以全知短演出自然接续。MS-10 的草稿可以展开再收起，但只有未发状态，不放一个必定失败的发送按钮。MS-24 写完道歉开头，将辩解性的尾句划去，纸仍未交付。

新增可玩细节：划去的字仍能辨认，折起后留一道折痕；再次展开时痕迹保留。删除或折叠不会自动使李晚云接受道歉。玩家可选先展开看一遍或直接收起，两者只影响私人动作顺序，不进入对方知识。

判定按宽区域点击 / 拖过短划线区，不识别字形；提供一键完成。状态为草稿阶段、折叠阶段、是否真实递交；读档不得把未发信变为已读信。资源复用纸张、两帧折纸与字层，简单至中等约 4–8 小时。声音用轻纸响与短键声，不以黑屏强制等待表现焦虑。

## 7. 辅助机制 S02：这道题我来算

用于 MS-05，保留作者指定的 520 数学互动。目标是让玩家参与少年最擅长、也正在分享的事情。它是明确的小计算，不冒充原创机制。

题目、数值输入、提交、提示、看解法同时可见；玩家可在旁边打开不判分的简易草稿栏，首版只提供两处数字记录，不做手写识别。比较端点得到 M=26，利用平方公式得到494，总和520。错误提示指向步骤，无嘲讽、无好感惩罚；全角数字 / 多余空格在实现时规范化，非法字符提示清楚。

完成或查看解法后进入 C01：不是答完弹“成功”，而是把自己已经懂的一步交给李晚云，让她写出最后一步。无需玩家重复输入同一答案。不会算也能走完整个角色交流，不影响剧情。

状态仅为答题节点是否完成与是否展开提示，提示使用不进入关系数据。退出保存输入或从该题起点恢复，需在实现时统一，不允许重复推进两段对白。简单至中等约 4–8 小时；输入框焦点、跳过与数值归一化需实际测试。

| 学习中的靠近 | C01 双方接续动作：中等、直观，有真实回应 | 同步点击节奏：简单，但易把合拍等同手速 | 选 C01；不做恋爱节奏评分 |

| 迁就与选择 | C03 并置意向与表：中等、后果具体 | 爱情 / 前途拉杆：低，但将真实考虑粗暴量化 | 选 C03；不引入隐藏人生评分 |

本版的组合特点，是**物件动作能形成习惯，角色会接续习惯，后续场景又保留这份习惯的痕迹**。不是每次点击都新奇；重复必须带来关系上的新信息。数学题、核酸码和整理杂物不需要全部包装成创新玩法。

## 9. 26 场体验分布与节奏

“核心”表示需要亲手体验并重点试玩；“轻交互”控制在少量动作；“演出”可以只用阅读推进，避免情绪被小游戏打断。下表覆盖全篇，不强行要求每场都有独立机制。

| 场景 | 本轮安排 | 操作改变什么 / 保持什么 | 体验重点 |
| --- | --- | --- | --- |
| MS-01 | 轻交互：搬一摞书，C01 的桌面入门 | 自己书的位置可变，换座固定 | 陌生空间 |
| MS-02 | 轻交互：看门口、拿饭卡 | 观察顺序可变，初次对话固定 | 认识她的节奏 |
| MS-03 | 轻交互：拾杯盖、收拾一次水迹 | 动作顺序不改变事故，配合对视演出 | 慌乱与注意到她 |
| MS-04 | 轻交互：拿码、既定时刻交出 | 不提供假提前归还选项 | 耍帅与她的实际反应 |

## 10. 音画与可用性统一规则

1. **动作有原因与回音**：移动纸页，对方的眼睛先跟过去，再伸手；不能拖到目标就瞬移进入下一句。响应延迟控制在可感知的短动作内，具体用试玩确定，不靠长等待冒充细腻。
2. **UI 不抢场景**：情绪段落减少底部大面板遮挡，把必要短提示放物件旁；字体清晰、对比足够，不为沉浸强迫玩家读手写小字。关键台词仍保留可回看文本。
3. **声音帮助理解**：纸声、笔声、脚步与铃声对应真实事件。音乐分配给段落，不根据隐藏“正确操作”升降；提供独立音量，静音仍可理解操作。
4. **鼠标与点击替代**：所有拖拽均有点选来源→点选目标方案，不依赖悬停、双击、持续长按、精细描线或短反应窗。触屏沿同一交互语义规划，仍需未来实际设备测试。
5. **暂停即暂停**：看文字、回看、设置、失去焦点不使人物错过约会；真实世界时间不结算人物责任。
6. **减少重复**：第一回完整学习，第二回缩短提示；同一动作第三次出现必须有反馈或意义变化，否则省略。小动作可以自动辅助，不影响情节。
7. **不抢角色的决定**：作品提供参与这段经历的空间；对没有人生分支的地方不承诺自由改命。也不拿隐藏收藏、正确回答或精准操作作为完整结尾资格。

## 11. 最小实现与验证顺序

当前工程是字符串数组对话和单方块点击，没有以上状态流程。首轮只验证 C01 + S02，使用独立测试场景和标注占位资源，保留现有菜单与原型。资源通过 Unity 创建与导入，不手写 GUID；此处列的是实施边界，本轮未修改代码。

### 第一份可玩验证：MS-05—06，约 3–5 分钟目标

- 桌面、男女主手部、两套布局、一道数学题、英语圈记；无整校背景、全配音或新剧情框架。
- 玩家计算→整理→交出→角色补写并递回→换到英语互助→收到角色主动圈记。
- 只需局部的互动步骤控制、物件放置、对话入口和结果回调；先不做完整存档、回放或泛用节点编辑器。
- 首轮目标是验证“她在和我一起做”，不是只测拖拽能不能成功。若成立，再加入 C02 的暂存 / 回来继续，最后补 C03。

### 工时预算

| 工作 | 初学者有效投入粗估 |
| --- | --- |
| C01 占位布局、交接与角色响应 | 12–20 小时 |
| S02 数值输入、提示、解法与对话衔接 | 4–8 小时 |

这是规划区间，不是交付承诺。C02/C03/S01 的估算都假定复用 C01，因此不可把所有数字相加当作整游戏预算。若成本超出，保留“玩家交出—角色接续—带着痕迹返回”，先减物件数量与手势帧数。

### 机制验收

| 检查 | 需要看到的证据 |
| --- | --- |
| 自然理解 | 第一次接触的人无需口头指导，能完成交接；卡住的具体位置被记录 |
| 真正参与 | 玩家能描述自己做了什么、对方怎样回应；不只回答“点下一步” |
| 布局有意义 | 两种布局均可完成，角色返回位置匹配；没有隐藏唯一正确摆法 |
| 情感回声 | 后续加入归还 / 独自翻页小样时，玩家能认出动作关系，不靠解释性旁白提醒 |
| 不误导责任 | 玩家理解失约和狠话是角色事件，不认为数学答错导致分手 |
| 功能可靠 | 重复点击不重复补写；中途退出不重复交书；UI 不穿透；跳过与手动得到相同剧情事实 |

正式实现时，自动化优先测试步骤重复提交、恢复边界、布局结果和剧情事实一致性；情感、手势自然程度与提示易懂性依赖实际试玩，不能用自动化测试证明“沉浸感达标”。建议先让三位未读剧本的人各试玩一次作定性观察，不把小样本当市场结论。

## 12. 本轮审查结论

当前最值得投入的是 C01：它能够贯穿相识、熟悉、归还和继续生活，又只依赖少量 2D 纸页与手势。C02 给关系投入以可执行的行动，C03 呈现作者确认的迁就轨迹。S01 与 S02 是辅助，不能喧宾夺主。

如果 C01 灰盒没有让玩家感到角色在参与，应该先改响应而非批量制作剩余 26 场。新的互动设计已完成这一轮可审阅规格；“实现完成”“试玩有效”“商业卖点成立”三个结论目前都不能作出。
