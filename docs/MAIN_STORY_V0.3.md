## 第一章：旁边的位置

### MS-01｜最后一排

**基本信息**：高一上学期，某日午前最后一节数学课；七班。凌赫、同桌、数学老师、班主任。约 2–3 分钟。【原设】聊天被抓、换座；【补写】搬书细节。

**导演与画面**：后排桌面占前景，后门在右后方。教室声音近而杂，黑板字可模糊处理。先让玩家认识一个普通、饿着肚子的学生。无抒情音乐。前排新座位与李晚云的桌子垂直相邻，后续俯视近景必须保持这一方向。

数学老师：「奇变偶不变，符号看象限。先看这个角——」

同桌［压低声音，用笔帽碰他的胳膊］：「中午吃什么？」

凌赫：「照烧鸡排饭。」

同桌：「又是这个？」

凌赫：「吃一辈子都吃不腻。」

同桌：「那一下课就走。昨天到我们就剩汤了。」

凌赫［把练习本往中间挪］：「我发现一条小道，从后面绕——」

他的手指刚划到纸边，身后传来声音。

班主任：「绕哪儿去？」

两人的笔同时落回题目上。

班主任：「凌赫，下课搬到讲台旁边。先换好座位，再去吃饭。」

［下课铃。椅子响成一片。同桌抱着饭卡站起来，看看他。］

同桌：「我给你看看还有没有。」

凌赫：「帮我守住最后一份。」

同桌：「这我可不敢答应。」

［凌赫抱起书，最上面的练习册往外滑了一截。他用下巴抵住，走到讲台右侧。］

李晚云：「杯盖……在你那边。」

凌赫：「哦。」

［他把杯子放好，拿着杯盖愣了半秒，才一起放下。］

### MS-05｜这道题

**基本信息**：同日晚自习及下课，七班；两位主角、朋友。约 4–6 分钟。【原设】留下讲题、数学题、约饭；【补写】讲解对白。

［李晚云在草稿上划去一行，又抄了一遍题目。下课铃响，她拿着本子站到凌赫旁边。］

李晚云：「这道题……你能帮我看一下吗？我算了好几次。」

朋友［从后排过来］：「凌赫，出去走走？闷死了。」

［凌赫看看门口，又看看递来的本子。］

李晚云：「没事，你去——」

凌赫：「你们先去，我这儿还有道题。」

［朋友点点头。凌赫把本子放到两人中间。］

凌赫：「你先算出什么了？」

李晚云：「顶点是六。我就把六代进去了，可算出来跟答案差好多。」

凌赫：「你找的是最小值。它问的是最大值，还给了区间。」

**题面窗口**：已知 f(x)=x²−12x−2，x∈[2,14]，M 为区间最大值。正实数 m、n 满足 m+n=26、mn=91。求 M+m²+n²。

**玩家输入**：数值框与“提交”，答案 520。空值提示“先填一个数”；错误提示“可以先比较区间端点”，不让李晚云嘲笑或掉好感。第二层提示展开 m²+n²=(m+n)²−2mn。可选“看解法”，均汇合下文。

凌赫［用笔点两个端点］：「这里是负二十二，这里二十六。开口向上，六在中间，所以最大的是二十六。」

李晚云：「后面不用把 m 和 n 分别解出来？」

凌赫：「不用。和的平方，减两倍的积。」

李晚云［自己补写］：「四百九十四……再加二十六，五百二十。」

凌赫：「对。」

［他像是也刚注意到结果，清了清嗓子。她低头把最后一行描清楚。此处不加告白解释。］

李晚云：「谢谢，我知道哪里错了。」

凌赫：「对了，今天帮你带码，你打算怎么报答我？」

李晚云［想一下］：「明天中午请你吃饭，行吗？」

凌赫：「行。食堂？」

李晚云：「不然呢？」

［两人第一次很自然地笑起来。］

**状态与转场**：查看解法与答对同样记录 `mathSceneComplete=true`、`lunchAgreed=true`；不保存“玩家笨”之类评价。MS-E05 → MS-06。

**Unity 备注**：现有对话框加数值输入面板、两级提示与解法图层；完成前防重复提交，关闭面板可恢复当前输入。纸笔共享只做短动画，不抢答题主功能。
