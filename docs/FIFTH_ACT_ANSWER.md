# 第五幕：默读、计算与答案输入

2026-11-02，按作者截图修订。先在题目特写中表现凌赫默读并发现“最大值/最小值”的错误，再由玩家填入整道题的结果；通过后才开始向李晚云讲解。其余故事内容、图片、音乐与章节解锁不变。

## 这一段的顺序

1. 李晚云说“顶点是六。我就把六代进去了，可算出来跟答案差好多。”后，切到题目特写。
2. 凌赫心声：“f(x) = x² - 12x - 2，x∈[2,14]……”；接着读到“最大值”，明白她代入顶点求成了最小值；再读m、n条件及最终求值。
3. “凌赫在草稿上写了几行，很快算出了结果。”出现输入框。框内保留完整题目，要求填写M+m²+n²的最终结果，不是只填M。
4. 空输入：“李晚云：你还没写呢。再看看？”；错误值：“李晚云：是这个答案吗？好像不太对，你再算算？”；保留当前输入允许修改，不扣分、不推进、不解锁。
5. 填520并确认后，输入框收起，在同一题目特写上显示原对白：“你找的是最小值。它问的是最大值，还给了区间。”随后接原有讲解、写答与约饭。

最终答案520：f(2)=-22、f(14)=26，M=26；m²+n²=26²-2×91=494，总和520。校验接受半角/全角整数和首尾空格；26、494、空输入、文字、520.0均不通过。没有跳过答题或直接看答案按钮，遵循作者要求；输入前不会自动显示520。
