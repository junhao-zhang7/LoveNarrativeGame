# 第一个互动小样：数学讲题—英语互助

2026-10-31。小范围实现 C01 + S02；几何桌面、矩形手部和文字是技术占位，不是正式美术，无正式音效。原菜单和 SampleScene 未改。

## 现在怎么运行

1. 回到 Unity，若正在 Play，先按顶部运行按钮停止。等待右下角导入 / 编译结束；Console 如有红色错误，先记录原文。
2. 顶部菜单点击 **Tools → Story Prototype → Open Table Slice**。如果提示保存当前场景，保存你的修改。工具会通过 Unity 创建 `Assets/_Game/Scenes/TableSlice.unity`；已有同名场景则直接打开，不覆盖。
3. 按 Unity 顶部三角形 **Play**，选择中间 **Game** 标签。画面应该出现“同一页 · 数学讲题与英语互助”。建议 Game 视图用 16:10 或 16:9，窗口足够大以便读字。
4. 输入答案（520），或点击提示 / 查看解法。错误不扣分。正确或查看解法后，点击“笔盒放左上 / 左下”，也可把笔盒拖到桌面左上或左下。
5. 将纸页拖到右侧绿色共同区域，或点击 **递给她（替代拖放）**。应看见占位手伸来、纸转向她、出现她补写的一行，然后纸返回。
6. 点击 **次日 · 英语互助**，再次递出练习册。她会留下前文时间圈记，随后显示结束。点击 **再体验一次** 可换另一种桌面摆法。

Esc 或右上“暂停”可暂停动画与输入；暂停界面点击继续。右上“重玩”回到题目，清除本轮圈记。离开小样或退出 Play 不保存当前互动进度，本轮还没有磁盘存档。

## 构建与检查入口

- **Tools → Story Prototype → Check Table Slice State**：在 Unity 中运行状态检查，结果写入忽略的 `TestResults/TableSlice/state-checks.txt`。
- **Tools → Story Prototype → Build Table Slice**：停止 Play 后使用；先处理未保存场景，再保存当前场景布局并构建，最后恢复原布局。只构建小样，输出 `Builds/TableSlice/TableSlice.exe`，不改变原有 Build Profiles 的场景列表。
- 独立程序的可选自动烟测参数为 `-batchmode -nographics -tableSliceSmoke -logFile 路径`；这部分代码已编写但尚未在 Player 执行，不能记为通过。它覆盖程序初始化与控制器流程，不替代真实鼠标 / 视觉测试。

## 本轮实际实现

| 文件 | 职责 |
| --- | --- |
| TableSliceState.cs | 局部状态与合法转换、答案规范化、提示层数、两种布局；拦截提前和重复事件 |
| TableSlicePresenter.cs | 运行时建立占位 UI、数学 / 英语对白与反馈、角色接纸动画、暂停与重玩 |
| TableSliceDrag.cs | UI 屏幕坐标转换、拖动范围、放置失败回位；拖放和替代按钮进入同一流程 |
| Editor/TableSliceBuilder.cs | 编辑器生成场景与资源引用、状态检查、单场景构建；通过编辑器保存，不手写 GUID |

执行顺序：问题完成 → 腾位置 → 可递纸 → 角色响应（锁住重复输入）→ 纸返回 → 英语互助 → 结束。状态保存在本场景的普通 C# 对象里，不写共享 ScriptableObject。数学与英语页文字暂放在小样组件内，仅用来验证一个机制；完整剧情数据配置仍使用原有数据 / 逻辑分离方向，不把这段代码升级成正式剧情框架。

## 第一次运行请检查

1. 错误答案不会前进；提示可使用；查看解法能进入整理步骤。
2. 两种笔盒位置都能递纸；放错回原位；替代按钮和拖放最终结果一致。
3. 动画期间连续点击不会出现两只手、重复圈记或跳过英语。
4. 暂停后手和纸停止，继续后能完成；失去窗口焦点不越过剧情。
5. 数学页和英语页字可读，无新增缺字 / NullReference 红色错误；结束重玩恢复题目、物品和空圈记。

当前没有自然手部插画、人物立绘、细致音效和完整剧情演出；用户判断体验时先看“动作是否被对方接续”，正式表现后续再迭代。若只觉得“拖到一个框里”，下一轮优先改对方的响应节奏和姿态。

## 学习要点

掌握三点：输入只提出动作，状态判断动作是否可发生，表现负责播放反馈；UI 坐标与屏幕像素需要转换；角色响应期间必须防重复提交。

动手练习：先使用按钮体验一次，再使用拖放体验一次，说明两种输入为何应得到同样结果。面试问题：为什么不能在每次点击时立即递增对话索引，同时启动一段未结束的动画？
