# 第三幕：俯视地面拖水（替代此前平视版）

2026-11-03。作者反馈平视拖把与地面不协调、水渍不明显，要求改成有水渍的地面俯视特写。本轮以此为当前方案，原平视版保留历史，不再用于小游戏。

## 画面与操作

采用接近垂直俯视的水磨石地面特写，主体是一大片边缘明显、带窗光倒影的水，右上角椅脚旁另有一小片水。拖把为同方向的俯视棉线头，保持固定大小，清理位置对准拖把头；不再使用竖立的平视长拖把或原场景桌椅遮挡区域。

有水图和配套干地面图构图一致，拖过的区域逐渐露出干地面，并短暂留下约10%湿痕再退去。渲染使用插画湿图到干图的透明度变化，不是用低透明度小椭圆冒充水，也不是流体模拟。提示框在画面上下边缘，主体水面位于中间。

顺序保留：拖主水渍 → 李晚云“这边还有一点” → 点凌赫“看到了” → 擦椅脚旁小水渍 → 放好拖把回座位 → 原湿袖口剧情。无倒计时、扣分或新分支。鼠标拖动与“帮我擦下一片”两种方式都能完成；暂停及原存档继续保留。未完成重进仍从该小游戏起点重做。

## 素材与实现

- 内置imagegen制作湿地面Wet.png、参考湿图制作干地面Dry.png、俯视拖把Tool.png。保存在art/Story/Act3/MopTopDown/，完整实际提示在PROMPTS.md。运行副本为Resources/Story/WaterCup/MopOverheadWet、MopOverheadDry、MopOverheadTool.png。作者原图及之前版本未覆盖。
- 拖把生成图带残余透明光晕，使用原生MopCutout材质在运行时剔除低透明度外围；未用图像脚本改写生成图。颜色和造型仍待作者验收，素材参考授权发行前另审。
- StoryMopPresentation将45个主清理采样点布置在水面范围，另外4个在椅脚小水渍上；拖动检测上一帧到当前帧的扫过线段，CleanPatch只清理实际触及区域。StoryMopState增加逐片清理入口，原两阶段门槛和旧Wipe入口保留。
- MopWetSurface预先为网格顶点记录最近清理点，透明度插值让湿图渐隐并露出干图；MopFurnitureGraphic旧平视遮挡逻辑不再调用。没有新增插件、后端、配音或音乐。

## 验证与作者验收

独立C#编译、旧清理状态检查和新增逐片清理的非法索引/补擦门槛/重复清理/重置检查已通过。Unity实际编译、湿/半干/全干三态1920×1080静态预览与Windows构建已通过（2026-11-03 14:14:55）；既有章节进度与其他互动检查通过。未代做Play或独立游戏拖动。

1. 打开Builds/MenuDemo/MenuDemo.exe →《旁边的位置》→ 第三幕，读到拿拖把后的小游戏。应直接看到俯视地面和明显的大水渍。
2. 按住鼠标让拖把头扫过水面，观察扫过区域变干；不同位置的拖把大小应一致，没有平视拖把悬在教室里。
3. 先擦一半，检查水和干地面对比是否足够明显；再擦完主水面，等晚云提醒后点击“看到了”，擦右上椅脚旁的小水渍。
4. 选“放好拖把，回到座位”接回原剧情。另试替代按钮、Escape暂停和未完成退出续读；之前解锁的章节应保留。

学习点：图片视角统一；清理判定与渲染透明度分开；采样点位置要对应玩家真正看到的水面。练习：从左往右只擦一半，观察湿图如何退去。面试问题：为什么要用上一帧到当前帧的线段做擦除判定，而不是只看当前鼠标点？
