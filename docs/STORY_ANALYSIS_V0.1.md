## 1. 核心判断

【原设】这是一段从高一换座开始的校园感情：凌赫与李晚云因邻座、互相讲题而靠近，在家校压力下分入不同学科班级，仍珍惜见面的机会；高二凌赫与新同桌周星落频繁讲题、数次失约，关系又被揭发，最终分手。作者已写定这条主线的分手结果，另留下“表面答应分手、秘密继续交往”的支线入口。

【解读】它最值得发展的命题是：**当喜欢不再能靠每天坐在身边自然维持时，两个人如何学会把对方纳入自己的生活，又如何承担替这段感情作出的选择？**

其中有三层情绪，而不只是“初恋输给现实”：

1. **被看见的快乐。** 凌赫先注意到一个人的脸，再逐渐注意到她等食堂、学数学、回消息的方式；李晚云从被帮助，走向主动问问题、请饭和拥抱。他们不是永远一方追逐、一方接受。
2. **被记得的需要。** 同桌时期不必约好就会相见；分班以后，每一次见面都需要腾出时间。喜欢仍在，维持喜欢所需的行为却变了。
3. **选择被误读的委屈。** 凌赫可能把改科理解为保护两人；李晚云可能既感激又害怕成为他放弃兴趣的理由。这层心理尚未写在原稿中，需用经历支撑，不能直接当事实。

玩家应先真实享受他们的相处，再看见习惯失效，而不是从第一分钟就被音乐提醒“这一切注定失去”。结尾不倒推此前的快乐为虚假，也不把继续交往或结束交往评价成道德等级。

## 3. 人物：欲望、矛盾与成长

### 凌赫

- **背景与习惯【原设】**：数学、物理强，喜欢历史政治；上课爱和同桌说话，爱照烧鸡排饭，与朋友关系好，有耍帅和开玩笑的欲望。不是没有学业目标的“恋爱脑”。
- **核心愿望【解读】**：既想按自己的兴趣生活，也想成为能解决问题、被朋友和喜欢的人需要的人。
- **恐惧与难舍【解读】**：怕自己无能为力，怕被当作需要大人管理的孩子；不愿失去兴趣、同伴认可和恋爱关系中的价值感。
- **行为倾向【原设→解读】**：出事后迅速做事补救；核酸码故意晚给、改科接受交易，都显示他倾向于“让我把这件事解决”，未必先询问对方需要什么。
- **不善表达【解读】**：选择后的不甘、做不到承诺的羞愧。他可能更容易解释“我没有别的意思”，而不是承认“我确实让你等了”。
- **自相矛盾【解读】**：保护关系而隐瞒关系；重视李晚云却低估等待的成本；本能享受被需要，却未分清助人与持续亲密的边界。
- **成长方向【提案 P02】**：从一次显眼的帮助，走向平常的说明、兑现和承认限制。不是变得不帮助周星落，而是不再把所有好意都当作没有代价。

核酸码情节尤其要诚实：他本来可以早给，却让她多承受一段窘迫。青春期的炫耀可以可爱，也可以不体贴；不要配“英雄救美成功”的积分、胜利音效或奖励镜头。保留李晚云确实产生好感，也允许这份好感与当时的不自在共存。

### 李晚云

- **背景与习惯【原设】**：英语好，常看书、低头，避开食堂高峰；父母限制手机；会主动求助、请饭、写日记、主动拥抱。害羞不等于没有行动力。
- **核心愿望【解读】**：希望在被安排的生活里拥有可以自己决定的一段关系；希望自己的主动被稳定回应，而不只在出状况时获得帮助。
- **恐惧与难舍【解读】**：怕给人添麻烦，也怕自己成为可以一直被推迟的人。家庭联系、自己的学业与关系都重要，不能以“为爱情反抗一切”简化她。
- **行为倾向【原设→解读】**：需求常先试探再退让，但积累到一定程度会明确行动——原稿已有主动拥抱和与父母争吵的支撑。
- **不善表达【解读】**：说清“我希望你来”的同时，不把它变成控制他的全部交往。
- **自相矛盾【解读】**：想独立决定，却会用“你不想和我一个班吗”影响对方；不想打扰，又希望对方察觉没说出口的期待。
- **成长方向【提案 P03】**：学会提出明确需要，允许对方说明做不到，也为自己的学科决定负责。二周目安排她独立处理一道题、作出学习安排，而不让全部私人场景都围绕等待凌赫。

【待定】她先想学理科、后改历史的内在原因还不足。数学薄弱、物理吃力不等于没有理科兴趣；文科好也不自动等于想学文。建议作者补一个她自己的兴趣或目标。不能为了显得独立，反过来宣称她完全没受恋爱影响。

### 周星落

【原设】认真、外表冷淡、不主动搭话，对凌赫例外，且不知道他已有恋人。

【解读】她的存在让凌赫此前“耐心教题”的行为产生了另一种社会含义，不负责替主角制造全部矛盾。她有钦慕之情，不代表每次问问题都在算计。

【提案 P04】给她最少量的独立性：她确实有不会的步骤，也能在说明时间后接受约到下一次。她可能珍惜被认真回应，担心贸然亲近被拒绝，所以用学习建立交流；这是待确认的心理，不是一周目直接展示的内心。她需要知道的边界由凌赫负责表达，不能要求她自动猜出秘密恋情。不增加三角恋攻略线、不让她突然“高冷恶毒”。

### 班主任与母亲

【原设】班主任促成互助、曾向母亲解释，后来用拥抱照片要求凌赫分手或改科。母亲严格限制手机、联系学校、要到校处理。

【解读】这两位成人可能都相信自己在保护学生，却用“管理风险”替代了解学生。班主任的支持与施压并存，正是值得写的矛盾，不需要替她辩护成绝对正确。

【提案 P05】班主任的可见立场是：优先维持学习秩序、向家长证明关系受到约束；她把不同分班去向当作可交代的安排。母亲担心学业与失去控制，具体家境、职业、创伤史不补写。成人的成长只需体现在一次愿意听完整理由的反应，不安排突然开明的大团圆。二人依旧要对强迫和羞辱的方式承担叙事上的责任。

## 4. 两难是否成立：不能跳过的因果检查

### 4.1 老师的二选一目前是最薄弱的支点

“不反对恋爱，却要求分手或改理科”并非完全不能成立，但原稿没交代她认为改科解决了什么。选科对人生影响远大于座位调整，不能把这种交换当正常教育建议。

**【提案 P05】保留原条件，补足其作为不公平条件的来由**：老师认为分班、减少同处、进入强管理班级能够回应家长，又用理科成绩解释其学业合理性。这里必须明确是她的判断，不是游戏证明“理科更有前途”。两班后来相邻可以保留：行政分班解决不了成人希望控制的所有事情，不能让角色事先假定一定相邻。

仍有三个必须见到的行动：凌赫追问为什么兴趣不能算理由；提出先和家长沟通；要求一点考虑时间。老师是否拒绝、拒绝理由、提交期限，均待作者确认。**不要凭空捏造学校政策，宣称其他办法客观不存在。**

若作者认为老师本就是过度干预的人，可以保留强硬语气；若本意是温和负责的老师，则这一条件与人物定位有冲突，需要作者决定如何修订。

接受此提案。老师可以向家长反应两个孩子选的说不同科目，将来不会分到一个班，谈恋爱的可能性大大降低，让家长认为从根源解决了问题。班主任对凌赫的态度可以先提议改科，如果不改科，将会把实际情况如实告诉李晚云家长。凌赫可以追问，并提出先和家长沟通，要求时间考虑，接受这点提议，并且应该要在当天晚自习结束后先告诉李晚云，一起考虑解决方法，最终的解决方法就是改科。其中的情节由你来写。

### 4.2 “吃醋 + 被发现”还不足以撑起最终分手

当前后半段缺少：约定究竟是什么、错过后怎么回应、她真正要求什么、他们尝试过什么。只写“闹小脾气”会使她显得不讲理；只写“他为她放弃文科”会使他天然占据道德高位。

**【提案 P06：分手过程扩写骨架】**：

1. **第一场失约**：保留原稿“讲题忘了时间”。让玩家事先知道约在哪里；不靠隐藏时钟判玩家输。
2. **一次说明**：李晚云指出具体等了哪次；凌赫解释确实在讲题。双方所说都真，但解释动机没有消除失约事实。
3. **一次修复且有效**：约定迟到时如何通知、哪天不约。至少一次成功见面，证明确实尝试过，且方法能帮忙。
4. **压力重新叠加**：恋情再被发现，原有通道减少。与其追加“周星落又故意出现”，不如让原先可行的安排不再稳定。限制的具体形式须作者确认，不能随意加全面监禁式家规。
5. **谈到选择的归属**：两人讨论改科；凌赫可以承认压力和不甘，不能把它换算成李晚云必须留下的债。她可以在乎承诺，也不能要求他停止帮助所有女生。
6. **尝试第三条路**：暂时减少见面、固定一个联系窗口、先以同学方式相处。至少认真评估两种，不能全用外部巧合打断。
7. **主线结束的真正决定**：如果李晚云明确不愿无限期等待，而凌赫也不能承诺一段稳定、可被承认的关系，结束才有支撑。谁先提出、是否都认可仍待定。这里不是数学证明“他们只能分手”，而是这两人在这一阶段作出的决定。

这段骨架是获授权范围内的扩写建议，尚非定稿。**如果后续作者让他们持续做到坦诚、兑现和明确期限，又没有新的不可调和条件，继续相处就同样合理；不能为了固定悲剧把所有沟通判无效。** 届时应调整主线交互权限或另开平行路线，而非惩罚细心玩家。

后半段我并没有具体写分手过程，是交给你来完成的。接受你的提案，按这个骨架来扩写。

### 4.3 正常人会想到的替代方案

| 方案 | 能解决什么 | 真实成本或仍存在的问题 | 本版态度 |
| --- | --- | --- | --- |
| 分班后继续交往 | 不必为同班放弃兴趣 | 需重新安排时间、说明交往边界 | 原稿已经实践；不能说分班就必然分手 |
| 保持史政地，向家长解释 | 保住兴趣与决定权 | 协商可能慢，未必获得认可 | 应认真提出，结果待作者补证，不伪造不允许申请 |
| 表面分手、秘密继续 | 暂缓公开冲突 | 不能自然公开关系，协调与隐瞒负担增加 | 作者已有支线，保留为后续独立路线 |
| 与周星落说明边界、改约讲题 | 解除她对关系状态的误判 | 凌赫需面对隐瞒；不能替代对李晚云的道歉 | 有效办法，不能强行让周星落拒不理解 |
| 固定见面或减少联系 | 减少无意义等待 | 一方可能觉得联系不足，另一方难承诺更多 | 值得试，不把成功一次等同永远可行 |
| 暂停到某个约定节点再谈 | 获得喘息与学业空间 | 不应要求对方无限保留恋人义务 | 可以形成不同人生路线，需另获作者批准 |
| 等到毕业后再决定 | 避开当前部分管束 | 等待很长且未来不保证；当下身份怎样定义仍需双方同意 | 不是万能答案，也不是应被嘲笑的天真方案

你可以将这些替代方案按你认为合理的方式加进去，没必要加太多，不要修改最后分手的结局。这个故事我想写的就是无论什么方案最终都会走向分手的结局。|

## 5. 情感曲线与表现尺度

| 段落 | 情绪走向 | 玩家主要经验 | 画面、声音和动作 |
| --- | --- | --- | --- |
| 换座 | 窘迫 → 陌生中的松动 | 抱书挪到不熟悉的位置 | 喧闹逐渐远去；课桌方向改变；不放恋爱主题曲 |
| 初次相助 | 慌乱 → 在意 → 有点得意 | 收拾意外、看见另一人的反应 | 杯子落地声、半步后退、视线短暂对上；不慢镜头逐项赞美容貌 |
| 讲题与午饭 | 被需要 → 熟悉 | 一起停在同一页，留出接话空隙 | 铅笔声、饭盘声；小幅推纸、收手；轻主题动机首次进入 |
| 纸条与雪 | 试探 → 欢喜 | 递出不能确定回应的东西 | 门外吵闹、纸声、快门；合照之后留短暂停顿即可 |
| 寒假与改科 | 想念 → 害怕 → 暂时松口气 | 有话可写，未必有合适时机送达 | 手机不回复不等于讨厌；办公室保留风扇/翻纸声，不用审判式低音 |
| 相邻班级 | 克服困难后的快乐 → 维护变费力 | 同样几步路开始需要约定 | 两间教室共用一条走廊，铃声一致，人流改变 |
| 失约与修复 | 失落 → 辩解 → 真正尝试 → 分歧 | 认出相同的讲题姿态，理解两侧不同成本 | 失约不立刻下雨；环境照常；让一次成功修复真的温暖 |
| 分手与回声 | 承认限制 → 空落 → 继续生活 | 决定如何结束当下，而非否认过去 | 桌上只需一本自己的书；不自动删照片；不追加多年痛哭旁白 |

不把每次脸红当作心理变化的唯一动画。可用翻页停顿、拿起又放下笔、让出半张桌面、整理已经整齐的书等具体动作。上述新增动作均属 P07 演出提案。

根据你认为好的方式增加情感曲线和表现尺度。

## 6. 情感意象与双视角价值

| 意象 | 初次 | 中期 | 原主线结尾 | 二周目新增理解 |
