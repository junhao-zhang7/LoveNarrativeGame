2026-11-03更新。作者允许按练习本方案完成寻路打磨。本轮保留原剧情、图中的地点/距离、最短路线、段落ID、章节解锁与续读规则；只改表现与操作反馈。

## 当前呈现

- 读完“我发现一条小道。”进入练习本特写：原教室画面轻微靠近并压暗，暖白双页练习本淡入，有横线、蓝灰封皮和页缝。左页画校园，右页记路线。
- 地点用教学楼/食堂小屋、花坛、转角等简笔图标表示。点击相连地点后，笔尖沿路段移动，约0.28秒写出一段笔迹，右页同步记下经过地点；选中的地点显示淡色圈。点回旧地点或“擦掉一段”时，末段笔迹约0.17秒收回；“重新画”回到起点。
- 到达后门后“指给同桌看”才可用。远路线由同桌提醒；最短路线成功后稍作停留，练习本约0.38秒退场，再接“从后面绕——”及老师画面。没有倒计时、扣分或失败结局。
- 新增0.18秒轻纸笔摩擦声，由固定随机种子的噪声在本地合成，跟随设置中的音效音量；没有新增配音或音乐。音色尚待作者试听。
- 暂停会冻结路线、笔迹与收起过程；空格/全局Enter不能跳过；收起期间不能重复提交。Escape仍可打开暂停页返回章节目录。

这是原生UI绘制的练习本近景，没有重绘原CG，也没有声称实现角色手部逐帧动画。点击地点连线，不是自由拖动画笔。地图数字是示意距离，不能当作实景米数或格数。

## 实现与制作成本

StoryRouteState仅负责相邻地点、撤回、路程与最短判定，本轮未修改。StoryRouteInput负责双页排版、简笔地标、右页记录、笔迹/笔尖动画和合成纸笔声。StoryScreen在原有未暂停阅读循环中调用TickRoute，让暂停、离开与剧情推进共用同一个状态入口。

没有新增资源GUID、依赖、付费插件或图片；素材台账记录代码绘图/合成声音的来源。书页、笔尖和路线都由既有UGUI组件生成，新增外部素材成本为零；最终风格与音色仍由作者验收。运行时只在首次画线时创建一份短音频，界面销毁时释放。

存档格式与内容版本4不变。退出未完成地图，续读仍回地图起点；已推进到老师对白后不重弹地图。已有解锁不清除。

## 请作者试玩

1. 打开新版MenuDemo，开始游戏 →《旁边的位置》→ 第一幕（已完成也可重看）。读到“我发现一条小道。”后继续，应淡入双页练习本，不能提前看见老师。
2. 点“操场边 → 食堂正门 → 食堂后门 → 指给同桌看”，应显示绕路提醒。看右页记录和左页笔迹是否对应，试“擦掉一段”和“重新画”。
3. 正确路线：教学楼后门（自动选中）→ 楼后转角 → 花坛缺口 → 食堂后门 → 指给同桌看。应先看见完成的路线，再收起练习本，接原悄悄话和班主任打断。
4. 画线途中按Escape，暂停时地图不变；恢复后可以接着画。收起期间连续点击也不能跳过老师对白。未完成时退出再续读，从地图起点开始；老师出场后再退出，续读应停在后续对白。
5. 设置→音效调为0再进入地图，应静音；恢复音效后检查纸笔声是否过尖/过轻。按自己的常用分辨率查看文字和数字是否清楚。原背景音乐、后续各幕保持原行为。

学习点：把“判定成功”和“完成演出后推进”分开；用同一未暂停更新入口驱动动画；把画面坐标和图上的距离分开。动手练习：比较370与160两条路线，观察同桌回应和右页记录。面试问题：为什么地图成功后还要锁住输入，再等待收起动画结束才推进剧情？
