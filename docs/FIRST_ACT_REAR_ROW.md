## 阅读方式

- 点击对话框或“继续”，先补全文字，再进入下一句；实现了空格 / Enter 的相同入口。
- 相邻图片以约 0.4 秒交叉淡入衔接，下课收书约 0.65 秒；转场期间不接受推进，避免跳句。
- Esc 暂停 / 继续；故事选择页 Esc 返回主菜单，本段结束页 Esc 返回故事选择。
- 开场标题已在故事卡显示，播放画面只留右上返回入口，避免左上章节纸片遮住从后门进入的班主任。

## 实现与学习

StorySequence / StoryBeat 保存“谁说什么、此时显示哪张图”；StoryProgress 约束当前段落与结束状态。StoryScreen 只负责加载已配置资源、显示图片与对白、逐字显示、转场及返回。MainMenuScreen 的开始入口打开故事选择，不再直接跳到互动灰盒。

Editor/RearRowStoryDraft 提供本段初始18段数据；MainMenuInstaller 仅在 RearRow.asset 不存在时经编辑器创建，不覆盖原有 Opening 草稿或后续作者修改。日后改对白可以在 Unity Inspector 中选择 Story/RearRow.asset 编辑；不要去改图片内的文字，因为图片不含对白。

一个知识点：数据与显示分开后，换一句对白只改资源，四张图的淡入逻辑不需要重复编写。

练习：在 Inspector 中给同桌的一句对白加一个标点，进入 Play 查看变化，然后恢复原稿。面试问题：为什么转场期间要阻止推进，同时对同一帧重复输入作防护？
