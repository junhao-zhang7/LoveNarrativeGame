## 学习与作品集记录
本轮重点：① Hub 管理编辑器，Editor 编译并运行 Unity 工程；② Assets、Packages、ProjectSettings 是源工程，Library 等是可再生成缓存；③ Git commit 是本地快照，push 才会写入远端。
练习：完成安装后，用自己的话解释为什么 .meta 需要提交，而 Library 不需要；运行 git status，判断每个新目录是否应入库。
