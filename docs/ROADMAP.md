- 已采用 Unity 6.6 的 Universal 2D 模板（URP）：用户已创建并打开工程；继续使用模板的 2D Renderer，不额外搭建渲染框架。

- 暂不制作正式 AI 美术、不采购素材、不决定售价；原型阶段使用标记清晰的几何占位。
- Phase 2：一个 15—20 分钟章节，加入经确认的特色交互、统一美术音频、设置和存档；真实玩家反馈是扩充内容的必要门槛。

- Phase 5：Windows 版本稳定后，按反馈评估移动适配。
