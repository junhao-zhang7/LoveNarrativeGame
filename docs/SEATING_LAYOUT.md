# 七班座位方位基准

2026-10-31。用户认可全部人物与整体画风，并提供一张照片，仅参考座位位置方位。本记录纠正初轮总览内的小场景及早期灰盒示意，不改变角色脸型、校服或已认可风格。

## 已明确的位置关系

1. 凌赫坐在讲台右手边，身体与桌面的使用方向正对前门 / 正门。
2. 李晚云紧邻凌赫的右手边。这里“右手边”以凌赫坐下后的自身方向为准，不是任意镜头的屏幕右侧。
3. 李晚云沿正常学生方向面向讲台 / 黑板；两人面向相差 90°，桌子也旋转 90°，形成直角邻接。
4. 不是两桌并排朝同一个方向，也不是两人隔着同一张桌面对面。椅子要落在各自实际使用的桌边，不能只让人物扭头伪装正确座位。

## 对镜头、道具和动作的影响

- 凌赫正看自己的本子时，视线是朝前门方向；注意李晚云需要向右转。李晚云从自己的学习方向转向凌赫，转的是自己的左侧。
- 递本是两张垂直桌面之间的斜向 / 转向交接，不是隔桌面对面直线滑动。各自写字的纸页和手腕方向也相差约 90°；可以为阅读做局部特写，但不能因此改变实体座位。
- 水杯仍按剧情放在李晚云桌面左上角；要以她的阅读方向确定左上，不以摄影机画面的左上代替。动画摆杯前在布局图中单独核对。
- 讲台、门和桌边属于固定空间。换近景、反打或过肩时保留同一空间关系，不镜像替换人物导致“右手边”反转。
